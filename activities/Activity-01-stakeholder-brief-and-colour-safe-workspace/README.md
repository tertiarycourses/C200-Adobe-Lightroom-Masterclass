# Activity 01 - Stakeholder Brief and Colour-Safe Workspace

**Course:** Adobe Lightroom Masterclass
**Course Code:** C200
**Alignment:** Topic 1
**Version:** v1.0 | 30 September 2026

## Purpose

Apply Lightroom and digital-image production decisions to a realistic client scenario and produce evidence that meets explicit acceptance criteria.

## Folder contents

- `source-images/` - authorised practice photographs
- `scenario-and-role-briefs.pdf` - client scenario and stakeholder perspectives
- `detailed-workflow.pdf` - click-by-click production procedure
- `worksheet.pdf` - questions and evidence workspace
- `acceptance-checklist.pdf` - final quality gate

## Evidence to submit

- Creative-brief translation worksheet
- Workspace readiness checklist
- Tool and file-format decision
- Two labelled experiment versions and consultation notes

Keep edited derivatives in a separate `evidence/` folder. Never overwrite the supplied source images.
